# Accessibility checklist

Reviewed the 10 static HTML pages: Home, About, Registration, Dashboard, Events, Assignments, Courses, Faculty, Results, and Timetable.

- [x] Each page declares English as its document language and includes a character set and viewport.
- [x] Each page has a page title and a top-level site heading.
- [x] Pages use semantic header, navigation, main, and footer regions.
- [x] The shared logo has alternative text.
- [x] Form controls have visible labels; registration controls also expose validation messages.
- [x] Navigation and theme controls are native buttons and links with accessible names.
- [x] The mobile menu exposes its expanded state and controlled navigation region.
- [x] Events status messages and FAQ expansion state are exposed to assistive technology.
- [x] Interactive elements have a visible keyboard focus style in the shared stylesheet.
- [x] Data tables use header cells for their columns.

The Events page also includes live status text for JSON loading, search results, and pagination.
