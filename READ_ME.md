# Student Hub Portal

## 📚 Overview
Student Hub is a multi-page web portal designed for students and faculty.  
It provides access to assignments, results, timetables, courses, faculty dashboards, and more — all in one place.

## 🖥️ Features
- **Assignments**: View subject-wise assignments, upload work, and track progress.
- **Results**: Check marks, grades, and overall performance summary.
- **Timetable**: Weekly schedule with breaks and lunch slots.
- **Courses**: Course details including faculty, credits, and duration.
- **About Us**: Information about academic, extra-curricular, and community activities.
- **Faculty Dashboard**: Faculty details with qualifications, experience, and contact info.

## 🛠️ Technologies Used
- **HTML5** for structure
- **CSS3** for styling
- **GitHub Pages** for hosting
